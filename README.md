# Akanksha Shukla — Portfolio

Static portfolio built with [Astro](https://astro.build). Deployed on Netlify.

## Run locally

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # output in dist/
```

## Update content

All content lives in `src/data/profile.ts` (profile, metrics, experience, projects, skills, education).
Resume PDF: `public/Akanksha-Shukla-Resume.pdf`.

Push to `main` → Netlify rebuilds and publishes automatically.
